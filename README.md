# RCWA+RT仿真

## 准备工作

### 创建环境

使用conda或venv等工具创建一个Python环境，Python版本不低于3.12。

### 安装依赖项

1. 从Github克隆dnois仓库
    ```shell
    git clone https://github.com/GjQAQ/dnois.git
    ```
2. 以开发模式安装dnois
    ```shell    
    pip install -e <path_to_dnois_repository>
    ```
3. 安装其它依赖项
    ```shell
    pip install -r requirements.txt
    ```
